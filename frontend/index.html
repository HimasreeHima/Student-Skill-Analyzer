About This Project

Student Skill Analyzer is a full-stack web application that helps students evaluate their skills and receive personalized career guidance. It is built using HTML, CSS, JavaScript and FastAPI, and will later integrate Machine Learning and Artificial Intelligence for smarter recommendations.
